One line of patch notes announcing that human sleep is fixed — the funniest one wins. The program writes a single deterministic changelog line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (145 characters, one line): the brain no longer replays every embarrassing moment since 2009 at 3 a.m., and sleep now installs in under 10 minutes, no restart required.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
